========================================================================
TROUBLESHOOTING
========================================================================

ImportError: No module named 'models'
  Solution: Ensure PYTHONPATH includes project root
            Run from project directory: cd FinalProject-Group5
            Use: export PYTHONPATH="${PYTHONPATH}:$(pwd)"

CUDA out of memory
  Solution: Reduce batch size in config.py
            Use CPU: export CUDA_VISIBLE_DEVICES=''
            Or reduce model hidden dimensions

Data download fails
  Solution: Check internet connection
            Verify API rate limits (yfinance)
            Check firewall/proxy settings

Virtual environment issues
  Solution: Delete venv/ and recreate: rm -rf venv && python3 -m venv venv
            Or use: python3 -m venv --clear venv
